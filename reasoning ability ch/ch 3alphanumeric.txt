1. CORE METHOD & GOLDEN SPEED FORMULAS (સુવર્ણ ગતિ સૂત્રો)
--------------------------------------------------------------------
A) The Direction Arithmetic Formula (દિશા સરવાળા-બાદબાકી નિયમ):
   ક્યારેય પણ પરીક્ષામાં સ્ક્રીન પર બે વાર ગણતરી કરવી નહીં! સીધું બીજગણિતીય સૂત્ર વાપરો:
   1. Same Directions -> SUBTRACT (-) (સમાન દિશા હોય તો બાદબાકી):
      * "Left to Left" (ડાબે છેડેથી... ના ડાબે) = (y - x)th from LEFT (ડાબેથી)
      * "Right to Right" (જમણે છેડેથી... ના જમણે) = (y - x)th from RIGHT (જમણેથી)
   2. Opposite Directions -> ADD (+) (વિરુદ્ધ દિશા હોય તો સરવાળો):
      * "Left to Right" (ડાબે છેડેથી... ના જમણે) = (y + x)th from LEFT (ડાબેથી)
      * "Right to Left" (જમણે છેડેથી... ના ડાબે) = (y + x)th from RIGHT (જમણેથી)

B) Preceded by vs Followed by (આગળ અને પાછળની ચોખ્ખી ઓળખ):
   - "Preceded by" (પહેલાં / આગળ / પૂર્વવર્તી): લક્ષ્ય ઘટકની બરાબર ડાબી બાજુ (આગળ)!
   - "Followed by" (પછી / પાછળ / અનુવર્તી): લક્ષ્ય ઘટકની બરાબર જમણી બાજુ (પાછળ)!
   - સુવર્ણ સૂત્ર:
     [ PRECEDING ELEMENT (આગળ) ]  ──►  [ TARGET (લક્ષ્ય) ]  ──►  [ FOLLOWING ELEMENT (પાછળ) ]
     ઉદાહરણ: "Symbols preceded by a number and followed by a letter":
              [ Number ] ──► [ Symbol ] ──► [ Letter ]

C) Dropping Rules (ઘટકો કાઢી નાખવાનો નિયમ):
   - જો પૂછવામાં આવે: "જો બધા જ નંબર્સ કાઢી નાખવામાં આવે, તો જમણે છેડેથી ૮મો ઘટક કયો?"
   - શોર્ટકટ: રફ કાગળ પર શ્રેણી ફરીથી લખવાની જરૂર નથી! સ્ક્રીન પર જમણે છેડેથી ગણવાનું શરૂ કરો અને આંગળી ફેરવતી વખતે બધા નંબર્સને અવગણીને (Skip કરીને) માત્ર અક્ષરો અને ચિહ્નો જ ગણો.

D) Position Values & Pair Counting (મૂળાક્ષર ક્રમ અને જોડી ગણતરી):
   - ફોરવર્ડ એન્કર: EJOTY (E=5, J=10, O=15, T=20, Y=25)
   - રિવર્સ સ્થાન: (27 - ફોરવર્ડ સ્થાન)
   - Pair Counting (જોડી ગણતરી): આગળ અને પાછળ બંને તરફ મોંથી ABCD બોલતાં બોલતાં શબ્દના અક્ષરો સાથે મેળવવું.
