1. CORE METHODOLOGY: THE 3-STATEMENT ELIMINATION ALGORITHM
--------------------------------------------------------------------
While Prelims tests 2-statement DS (Ch 10), RRB PO Mains features 3-statement Data Sufficiency.
Follow the systematic 3-phase elimination tree:

Phase 1: Individual Testing (એકલા વિધાનોની ચકાસણી)
- Test Statement I alone.
- Test Statement II alone.
- Test Statement III alone.
- If any single statement gives a unique definitive answer, eliminate options requiring combinations!

Phase 2: Two-Statement Combinations (બે-બે વિધાનોની જોડી)
- Test (I + II).
- Test (II + III).
- Test (I + III).
- If any pair gives a unique answer, STOP! Do NOT test all three together.

Phase 3: All Three Together (ત્રણેય વિધાનો એકસાથે)
- Test (I + II + III) ONLY when no two-statement pair was sufficient.
- If all three combined still leave ambiguity or multiple possibilities, mark:
  "Data in all three statements together are not sufficient."

--------------------------------------------------------------------
2. THE UNIQUENESS PRINCIPLE (અદ્વિતીય ઉત્તર સિદ્ધાંત)
--------------------------------------------------------------------
1. Exactly ONE Answer:
   - Data is sufficient if and only if exactly ONE answer is determined.
   - Example: If the question asks "Who is the tallest?", and combining statements says "Either A or B is tallest", then the data is NOT SUFFICIENT!
2. Definite Negative is Also Sufficient:
   - If the question asks "Is X taller than Y?", and the data conclusively proves "NO, X is shorter than Y", this is 100% SUFFICIENT! A definitive 'NO' is a valid answer.
3. The Stop-Solving Law (સમય બચાવવાનો નિયમ):
   - Never solve the problem to the very end or compute exact final coordinates.
   - The moment you know that a unique answer is guaranteed, STOP solving and mark the sufficient combination. This saves 40-50 seconds per question!

--------------------------------------------------------------------
3. TOPIC-WISE SUFFICIENCY CRITERIA & COMMON EXAM TRAPS
--------------------------------------------------------------------
A) Seating Arrangements (બેઠક વ્યવસ્થા):
   - Trap: Knowing the two neighbors of P without knowing whether P faces Inside or Outside!
   - Condition: Relative position is fixed ONLY when facing orientation is known.

B) Blood Relations (લોહીના સંબંધો):
   - Trap: Assuming gender from names (e.g., assuming 'Kiran' is male).
   - Condition: Gender MUST be explicitly stated or deduced through relationship terms (e.g. "father", "sister", "husband").

C) Direction Sense (દિશા અને અંતર):
   - Trap: Knowing turns (left, right) without knowing the starting heading direction (North/South/East/West).
   - Condition: Both starting orientation and distances must be linked to a common anchor.

D) Order & Ranking (ક્રમ અને સરખામણી):
   - Condition: Total number of persons must be known to convert between top rank and bottom rank.
