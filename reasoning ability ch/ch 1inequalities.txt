1. CORE METHOD: THE OPEN-GATE METHOD (ખુલ્લા દરવાજાની પદ્ધતિ)
--------------------------------------------------------------------
A) How the Gate Works (દરવાજો કેવી રીતે કામ કરે છે?):
   - '>' : Gate is OPEN from Left to Right (ડાબેથી જમણે દરવાજો ખુલ્લો છે). You can travel A -> B.
           Gate is CLOSED from Right to Left (જમણેથી ડાબે દરવાજો બંધ છે). You CANNOT travel B -> A.
   - '<' : Gate is OPEN from Right to Left (જમણેથી ડાબે દરવાજો ખુલ્લો છે). You can travel B -> A.
           Gate is CLOSED from Left to Right (ડાબેથી જમણે દરવાજો બંધ છે). You CANNOT travel A -> B.
   - '=' : Gate is OPEN from BOTH sides! (બંને તરફથી દરવાજો હંમેશા ખુલ્લો રહે છે). A <-> B freely.
   - '≥' or '≤' : Same as '>' or '<', but carries an 'equal' mat at the bottom (પગ નીચે સમાનતાની સાદડી રહે છે).

B) Opposing Gates (Path Blocked / No Relation - સામસામા દરવાજા):
   - Whenever opposing signs face each other:
     Example: A > B < C   OR   A < B > C   OR   A ≥ B ≤ C
     The gate is BLOCKED between A and C! (રસ્તો સંપૂર્ણ બંધ થઈ જાય છે).
     You cannot travel from A to C, and you cannot travel from C to A.
     Any direct conclusion like A > C or A < C is immediately FALSE (અચોક્કસ/ખોટું)!

C) The 3-Tier Hierarchy (The Kingdom Rule - પ્રાથમિકતાનો નિયમ):
   1. King (Priority 1): '>' or '<' (રાજા)
      - Rule for 'A > B' to be TRUE:
        * Path must be completely open from A to B (રસ્તો સંપૂર્ણ ખુલ્લો હોવો જોઈએ).
        * At least ONE King ('>') must appear along the path! (રસ્તામાં ઓછામાં ઓછો એક રાજા હોવો જ જોઈએ).
   2. Soldier (Priority 2): '≥' or '≤' (સૈનિક)
      - Rule for 'A ≥ B' to be TRUE:
        * Path must be completely open from A to B.
        * The 'equal' sign must NEVER drop! Every single gate on the path must have '≥' or '='!
          (રસ્તાના દરેક દરવાજા પર સમાનતા '=' ની સાદડી હોવી જ જોઈએ. જો એક પણ દરવાજા પર '=' છૂટી ગયું, તો A ≥ B ખોટું પડશે!).
   3. Citizen (Priority 3): '=' (સામાન્ય પ્રજા)
      - Rule for 'A = B' to be TRUE:
        * Every single step between A and B must strictly be '='! (બધા જ ચિહ્નો માત્ર ને માત્ર '=' જ હોવા જોઈએ).

D) The Two 'Either-Or' Conditions (કાં તો I અથવા II ના નિયમો):
   - Case 1 (Splitting of a Single Relation - બે સંબંધોનું વિભાજન):
     Statement gives: A ≥ B
     Conclusions: I. A > B,  II. A = B
     Both individual conclusions are doubtful on their own, but together they cover A ≥ B completely.
     -> Answer: [C] Either I or II follows! (કાં તો I અથવા II અનુસરે છે).
   - Case 2 (Opposing Signs / Blocked Path - ૩ ચિહ્નોનો નિયમ):
     Path between A and B is blocked (e.g., A > M < B).
     All 3 comparison signs must be present: (A > B, A < B, A = B).
     Example:
       Statement: A > M < B
       Conclusions: I. A ≥ B,  II. A < B   (Together they cover >, =, <)
     -> Answer: [C] Either I or II follows!

E) Coded Inequality: The 2-Second Magic Box (Mains Protocol):
   Layout:
        >     |    ≥
     ---------|---------
        <     |    ≤
              =
   - Top-row symbols talk only to top-row; Bottom-row symbols talk only to bottom-row.
   - Cross-diagonal travel immediately blocks the gate!


2. THREE SOLVED EXAM EXAMPLES (પરીક્ષાના ઉદાહરણો)
--------------------------------------------------------------------
[Example 1 - Direct Prelims Shift 1 Model]:
Statements: P ≥ Q = R > S ≥ T
Conclusions: I. P > S   |   II. R > T
• Conclusion I (P > S):
  Path: P -> Q -> R -> S. P ≥ Q (ખુલ્લું), Q = R (ખુલ્લું), R > S (ખુલ્લું, રાજા હાજર).
  રસ્તો ખુલ્લો છે અને રાજા (R > S) હાજર છે -> Definitely TRUE!
• Conclusion II (R > T):
  Path: R -> S -> T. R > S (રાજા હાજર), S ≥ T (ખુલ્લું).
  રસ્તો ખુલ્લો છે અને રાજા હાજર છે -> Definitely TRUE!
Answer: Both conclusions I and II follow (બંને અનુસરે છે).

[Example 2 - Multi-Statement Combined Model]:
Statements: A > B ≥ C;  D < C = E
Conclusions: I. A > D   |   II. B ≥ E
• Common bridge variable is C (સામાન્ય કડી C છે).
  D < C ને ઉલટાવીને C > D લખો.
  સંયુક્ત સાંકળ: A > B ≥ C = E > D.
• Conclusion I (A > D): Path A -> B -> C -> D: A > B (રાજા) ≥ C > D (રાજા). રસ્તો ખુલ્લો, રાજા હાજર -> TRUE!
• Conclusion II (B ≥ E): Path B -> C -> E: B ≥ C = E. સમાનતા '=' ક્યાંય છૂટતી નથી -> TRUE!
Answer: Both conclusions I and II follow.

[Example 3 - Blocked Path Either-Or Model]:
Statements: X > Y < Z
Conclusions: I. X ≥ Z   |   II. X < Z
• X અને Z વચ્ચે સામસામા ચિહ્નો (> અને <) હોવાથી રસ્તો બ્લોક છે.
• બંને નિષ્કર્ષ વ્યક્તિગત રીતે અચોક્કસ/ખોટા છે.
• ચલ સમાન છે (X અને Z). ત્રણેય સંબંધો (>, =, <) આવરી લેવાય છે.
Answer: Either I or II follows (કાં તો I અથવા II અનુસરે છે).


3. COMMON EXAM TRAPS (સામાન્ય પરીક્ષાની ભૂલો)
--------------------------------------------------------------------
1. Dropping the Equal sign (સમાનતાની સાદડી છૂટી જવી):
   જો વિધાન A ≥ B = C > D હોય, તો A ≥ D ન કહી શકાય, કારણ કે C > D માં રાજા આવી ગયો અને '=' છૂટી ગયું!
2. Inverting '<' incorrectly (ઊંધા ચિહ્નને ખોટી રીતે વાંચવું):
   જ્યારે D < C આપ્યું હોય, ત્યારે ઉતાવળમાં D > C ન લખવું. હંમેશા યાદ રાખો: મોં C તરફ ખુલે છે એટલે C > D થાય!
3. Either-Or False Alarm (ખોટો Either-Or વહેમ):
   બંને નિષ્કર્ષ ખોટા હોય એટલે હંમેશા Either-Or ન થાય. ચલ સરખા હોવા જોઈએ અને જરૂરી ચિહ્નો હોવા જોઈએ!
