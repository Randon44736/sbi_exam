1. CORE METHOD: THE OPEN-GATE METHOD (ખુલ્લા દરવાજાની પદ્ધતિ)
--------------------------------------------------------------------
A) How the Gate Works (દરવાજો કેવી રીતે કામ કરે છે?):
   - '>' : Gate is OPEN from Left to Right. You can travel A -> B.
           Gate is CLOSED from Right to Left. You CANNOT travel B -> A.
   - '<' : Gate is OPEN from Right to Left. You can travel B -> A.
           Gate is CLOSED from Left to Right. You CANNOT travel A -> B.
   - '=' : Gate is OPEN from BOTH sides! You can travel freely A <-> B.
   - '≥' or '≤' : Same as '>' or '<', but carries an 'equal' mat at the bottom.

B) Opposing Gates (Path Blocked / No Relation - સામસામા દરવાજા):
   - Whenever opposing signs face each other:
     Example: A > B < C   OR   A < B > C   OR   A ≥ B ≤ C
     The gate is BLOCKED between A and C!
     You cannot travel from A to C, and you cannot travel from C to A.
     Any direct conclusion like A > C or A < C is immediately FALSE!

C) The 3-Tier Hierarchy (The Kingdom Rule - પ્રાથમિકતાનો નિયમ):
   1. King (Priority 1): '>' or '<'
      - Rule for 'A > B' to be TRUE:
        * Path must be completely open from A to B.
        * At least ONE King ('>') must appear along the path!
   2. Soldier (Priority 2): '≥' or '≤'
      - Rule for 'A ≥ B' to be TRUE:
        * Path must be completely open from A to B.
        * The 'equal' sign must NEVER drop! Every single gate on the path must have '≥' or '='!
        * If even ONE King ('>') appears without '=', 'A ≥ B' becomes FALSE!
   3. Citizen (Priority 3): '='
      - Rule for 'A = B' to be TRUE:
        * Every single step between A and B must strictly be '='!

D) The Two 'Either-Or' Conditions (કાં તો I અથવા II ના નિયમો):
   - Case 1 (Splitting of a Single Relation - બે સંબંધોનું વિભાજન):
     Statement gives: A ≥ B
     Conclusions: I. A > B,  II. A = B
     Both individual conclusions are doubtful on their own, but together they cover A ≥ B completely.
     -> Answer: [C] Either I or II follows!
   - Case 2 (Opposing Signs / Blocked Path - ૩ ચિહ્નોનો નિયમ):
     Path between A and B is blocked (e.g., A > M < B).
     All 3 comparison signs must be present: (A > B, A < B, A = B).
     Example:
       Statement: A > M < B
       Conclusions: I. A ≥ B,  II. A < B   (Together they cover >, =, <)
     -> Answer: [C] Either I or II follows!

E) Coded Inequality: The 2-Second Magic Box (Mains Protocol):
   Layout:
        >     |    ≥
     ---------|---------
        <     |    ≤
              =
   - Top-row symbols talk only to top-row; Bottom-row symbols talk only to bottom-row.
   - Cross-diagonal travel immediately blocks the gate!


2. THREE SOLVED EXAM EXAMPLES
--------------------------------------------------------------------
[Example 1 - Direct Prelims Shift 1 Model]:
Statements: P ≥ Q = R > S ≥ T
Conclusions: I. P > S   |   II. R > T
Solution:
• Conclusion I (P > S):
  Path: P -> Q -> R -> S.
  P ≥ Q (open), Q = R (open), R > S (open).
  Since the path is open and at least one King (R > S) is present, P > S is definitely TRUE.
• Conclusion II (R > T):
  Path: R -> S -> T.
  R > S (open, King), S ≥ T (open).
  Path is open and King is present -> definitely TRUE.
Answer: Both conclusions I and II follow.

[Example 2 - Multi-Statement Combined Model]:
Statements: A > B ≥ C;  D < C = E
Conclusions: I. A > D   |   II. B ≥ E
Solution:
• Common bridge variable is C.
  Reverse D < C to C > D.
  Combined Chain: A > B ≥ C = E > D.
• Conclusion I (A > D):
  Path A -> B -> C -> D: A > B (King) ≥ C > D (King). Path open, King present -> TRUE!
• Conclusion II (B ≥ E):
  Path B -> C -> E: B ≥ C = E. Equal never dropped! -> TRUE!
Answer: Both conclusions I and II follow.

[Example 3 - Blocked Path Either-Or Model]:
Statements: G ≥ H = I;  K < J = I
Conclusions: I. G > K   |   II. G ≤ K
Solution:
• Chain: G ≥ H = I = J > K.
  Wait, let's test G vs K:
  G ≥ I = J > K  ==> G > K is definitely TRUE! (Not either-or).
  Now check:
  Statements: X > Y < Z
  Conclusions: I. X ≥ Z   |   II. X < Z
  Path between X and Z is blocked by opposing signs (> and <).
  Both individual conclusions are false/uncertain.
  Subject and predicate are identical (X and Z).
  Between X and Z, three relationships are possible: X > Z, X = Z, X < Z.
  Conclusions I and II cover all three: (X > Z or X = Z) and (X < Z).
Answer: Either I or II follows!


3. COMMON EXAM TRAPS (સામાન્ય પરીક્ષાની ભૂલો)
--------------------------------------------------------------------
1. Dropping the Equal sign:
   If Statement is: A ≥ B = C > D ≥ E.
   Can we say A ≥ E? NO! Because of the King '>' between C and D, the equal mat dropped!
2. Inverting '<' incorrectly:
   When given D < C, students often write D > C by mistake. Always remember: open mouth points to C!
3. Either-Or False Alarm:
   Just because both conclusions are False does NOT mean it is Either-Or!
   Check: Are subject and predicate same? Are all required signs present?
