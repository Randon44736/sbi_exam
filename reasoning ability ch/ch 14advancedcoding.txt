1. CORE METHODOLOGIES & DECODING BLUEPRINT (મુખ્ય પદ્ધતિ અને ડિકોડિંગ નિયમો)
--------------------------------------------------------------------
In modern IBPS RRB PO Mains exams, Coding-Decoding is NOT simple Chinese word elimination. Each word is coded into a structured triplet:
            [SYMBOL] [NUMBER] [LETTER]   (e.g., 'BANKING' → '@ 7 T')

A) The 3-Component Decoding Protocol (ત્રિ-પરિમાણીય ડિકોડિંગ નિયમ):
   1. Deciphering the Number (સંખ્યા ઓળખવાની ટેકનિક):
      * Word Length (શબ્દની લંબાઈ): Check if code numbers directly match word character counts (e.g., 4, 6, 7).
      * Vowel / Consonant Count: Number of vowels (A, E, I, O, U) or consonants.
      * Positional Rank: Alphabetical rank of the first or last letter (e.g., A=1, B=2 ... Z=26).
   2. Deciphering the Letter (અક્ષર ઓળખવાની ટેકનિક):
      * Opposite Letter (વિરોધી અક્ષર - સરવાળો ૨૭):
        - A-Z, B-Y, C-X, D-W, E-V, F-U, G-T, H-S, I-R, J-Q, K-P, L-O, M-N.
        - Check if code letter is opposite of the 1st or Last letter!
      * Adjacent Shifts (+1 / -1): Next (+1) or previous (-1) letter of the last letter or middle letter.
   3. Deciphering the Symbol (પ્રતીક ઓળખવાની ટેકનિક):
      * First Letter Family: Words starting with the same letter get the same symbol (e.g., all words starting with 'P' get '%', 'M' get '#').
      * Even / Odd Word Length: If only 2 symbols exist in the whole set (e.g. only '&' and '%'), Even length words get one symbol and Odd length get another!

B) Conditional Coding Architecture (શરતી કોડિંગ નિયમો):
   1. Digits/Letters are coded based on a reference table.
   2. Conditions (શરતો) must be applied strictly:
      * Condition 1: If 1st element is vowel & last is consonant $\to$ swap their codes.
      * Condition 2: If both 1st and last elements are odd numbers $\to$ code both as special symbol (e.g., '*').
      * Condition 3: If an element is immediately preceded by an even number $\to$ apply specific transformation.
   3. Golden Scanning Rule: Scan strictly LEFT-TO-RIGHT. Never apply overlapping condition triggers!

C) Binary Coding System (બાઈનરી કોડિંગ - ઘાતાંક ૨ ની શ્રેણી):
   * 0 is represented by a specific symbol (e.g., '$').
   * 1 is represented by another symbol (e.g., '#').
   * Decimal to Binary Conversion via Powers of 2 (16, 8, 4, 2, 1):
     - Example: $13 = 8 + 4 + 0 + 1 = 1101_2 \implies \text{# # \$ #}$!
     - Example: $22 = 16 + 4 + 2 = 10110_2 \implies \text{# \$ # # \$}$!

2. COMMON EXAM TRAPS (સામાન્ય પરીક્ષાની ભૂલો અને સાવચેતી)
--------------------------------------------------------------------
1. Multi-Condition Interference Trap: શરતી કોડિંગમાં એક કરતાં વધુ શરતો લાગુ પડતી હોય ત્યારે પ્રશ્નની પ્રાથમિકતા (Hierarchy) ચકાસ્યા વગર સીધો ફેરફાર કરવાની ઉતાવળ કરવી નહીં.
2. Opposite Letter Miscount: વિરોધી અક્ષર શોધતી વખતે સરવાળો ૨૭ થવો જોઈએ (દા.ત. L(12) નો વિરોધી O(15) થાય, N(14) નહીં).
3. Even/Odd Symbol Misidentification: માત્ર એક શબ્દ જોઈને સિમ્બોલ નક્કી ન કરવો; તમામ ૪ શબ્દોના સિમ્બોલ્સ ચકાસીને જ સામાન્ય પેટર્ન નક્કી કરવી.

   - For option [B] MUSIC:
     * Starts with 'M' $\to$ `#`
     * Length = 5 letters $\to$ `5`
     * Last letter is 'C' (Rank 3). The opposite letter of 'C' is $27 - 3 = 24 \implies$ **X**!
     * So code for 'MUSIC' is `#5X` (not `#5V`)!

   - Symbol `#` $\implies$ Word starts with **'M'**!
   - Number `5` $\implies$ Word length is exactly **5 letters**!
   - Letter `V` $\implies$ Code letter is 'V' (Rank 22).
     Since Code Letter = Opposite of word's last letter:
     $$\text{Last Letter Rank} = 27 - 22 = \mathbf{5 \implies E}!$$
     *(Remember: E-V opposite pair $\implies$ "LOVE" or "EVening")*

Binary Coding Blueprint:
In modern banking exams, numbers are coded using only two symbols (e.g. '$' and '#').
- '0' is coded as '$'
- '1' is coded as '#'
- '2' is coded as '# $' (Binary 10 = 2)
- '3' is coded as '# #' (Binary 11 = 3)
- '4' is coded as '# $ $' (Binary 100 = 4)
The values double with each position from right to left:
  Position Values: ... 32, 16, 8, 4, 2, 1

Decimal to Binary Conversion Formula:
Express the target decimal number as the sum of powers of 2.
Write '#' for powers used (1), and '$' for powers not used (0)!
