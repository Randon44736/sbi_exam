1. CORE METHOD: THE DUAL-AXIOM VENN FRAMEWORK
--------------------------------------------------------------------
A) The "Only a Few" Rule (માત્ર થોડાક જ - બેવડો નિયમ):
   - "Only a few A are B" is a COMPOUND statement containing TWO facts:
     1. Some A are B (કંઈક A એ B છે)   -> POSITIVE overlap
     2. Some A are NOT B (કેટલાક A એ B નથી) -> NEGATIVE restriction
   - Critical Asymmetry (દિશા મહત્વની છે!):
     * Can ALL A be B? -> ❌ NEVER! (Always 0% probability).
     * Can ALL B be A? -> ✅ YES, A POSSIBILITY! (B has no restriction).

B) The "Only A are B" Inversion Rule (માત્ર A જ B છે):
   - "Only A are B" = "All B are A", WITH AN EXCLUSIVE LOCK!
   - B becomes the personal property of A.
   - B can NEVER touch C, D, or any other entity!

C) The Golden Possibility Rules (શક્યતાના સુવર્ણ નિયમો):
   1. If a relation is ALREADY 100% DEFINITELY TRUE -> Possibility is ❌ FALSE!
      Example: If All A are B, then "Some A can be B is a possibility" is FALSE.
   2. If a relation is 100% IMPOSSIBLE -> Possibility is ❌ FALSE!
      Example: If No A is B, then "All A can be B is a possibility" is FALSE.
   3. If a relation is UNKNOWN / DOUBTFUL in the direct Venn diagram ->
      Possibility is ✅ TRUE!

D) The Two 'Either-Or' Complementary Pairs (કાં તો I અથવા II ના જોડીઓ):
   - Condition 1: Both individual conclusions must be False / Doubtful.
   - Condition 2: Same two elements (Subject and Predicate) in both conclusions.
   - Condition 3: Must form one of these two pairs:
     * Pair A: Some + No   (Elements can be parallel or cross: A-B, A-B OR A-B, B-A)
     * Pair B: All + Some Not (Elements must be in parallel order: All A are B + Some A are not B)
   - ⚠️ TRAP: "All + No" NEVER forms an Either-Or pair!
