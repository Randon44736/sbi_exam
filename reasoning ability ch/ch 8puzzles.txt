1. CORE METHOD & GOLDEN PUZZLE SOLVING PROTOCOLS (પઝલ ઉકેલવાના સુવર્ણ સિદ્ધાંતો)
--------------------------------------------------------------------
A. FLOOR PUZZLE METHODOLOGY (7 & 8 Floors):
   • Standard Numbering: Ground floor is 1, above is 2, ..., topmost is N. NEVER invert!
     (ગ્રાઉન્ડ ફ્લોર હંમેશા ૧ અને સૌથી ઉપરનો માળ N રહેશે. ક્યારેય ક્રમ ઊંધો ન કરવો!)
   • Gap Distance Formula:
     - "K persons live between A and B" => |Floor_A - Floor_B| = K + 1.
     - "A અને B વચ્ચે 3 વ્યક્તિઓ રહે છે" => માળ વચ્ચે 4 નો તફાવત (|A - B| = 4).
   • Immediate Positions:
     - "A lives immediately above B" => Floor_A = Floor_B + 1.
     - "A lives immediately below B" => Floor_A = Floor_B - 1.
   • The 2-Case Execution Law (બે સમાંતર કેસ પદ્ધતિ):
     - રફ પેપર પર તરત Case 1 અને Case 2 એમ બે સ્તંભ દોરો.
     - કોઈપણ શક્યતા મનમાં રાખવાને બદલે સીધી ડાયાગ્રામમાં મૂકો. જ્યાં વિરોધાભાસ આવે ત્યાં તે કેસ છેકી નાખો!

B. BOX STACKING METHODOLOGY (7 to 9 Boxes):
   • Dynamic Relative Blocks (તરતા બ્લોકની રીત):
     - બોક્સ પઝલમાં શરૂઆતમાં કોઈ ચોક્કસ માળના નંબર નથી હોતા.
     - શરતો પરથી સીધા "લેગો બ્લોક્સ" બનાવો (જેમ કે [S-R બ્લોક], [V-T-P બ્લોક]).
   • Boundary & Height Limit:
     - કુલ સ્ટેકની ઊંચાઈ આપેલા કુલ બોક્સની સંખ્યા N કરતાં વધવી ન જોઈએ.
     - જેવું છેડાનું બોક્સ (સૌથી ઉપર કે સૌથી નીચેનું) મળે કે તરત બાકીના બ્લોક જોડી દો.
   • Gap Formula:
     - Pos X અને Pos Y વચ્ચેના બોક્સ = |X - Y| - 1.

C. MONTH-DATE SCHEDULING METHODOLOGY (2-3 Months x 2 Dates):
   • Calendar Base Anchors (મહિનાના દિવસો યાદ રાખવાની ટ્રીક):
     - 30 દિવસવાળા મહિના: April, June, September, November (AJSN - માત્ર ૪ જ મહિના!).
     - 31 દિવસવાળા મહિના: January, March, May, July, August, October, December (૭ મહિના).
     - 28/29 દિવસ: February.
   • The Chronological Leap (સમયરેખાનો નિયમ):
     - "11 એપ્રિલની તરત પહેલાં" = "24 માર્ચ" (કેલેન્ડર મુજબ અગાઉનો સ્લોટ, અગાઉનો મહિનો નહીં!).
   • Odd-One-Out Grouping Traps (અલગ પડતું જૂથ ઓળખવાની રીત):
     - 95% બેન્કિંગ પ્રશ્નોમાં અલગ પડતું તત્વ કાં તો મહિનાના દિવસો (30 vs 31) અથવા તારીખની એકી-બેકી (Odd vs Even) પરથી પકડાય છે!

[Puzzle 1 - 7-Floor Building (Q8.1 - Q8.3)]:
Setup: 7 persons (A, B, C, D, E, F, G) on 7 floors (1 to 7).
Clues:
1. D lives on an odd-numbered floor above floor 4 -> D = Floor 5 or Floor 7.
2. Three persons live between D and B:
   - Case 1: D=5 -> B = Floor 1.
   - Case 2: D=7 -> B = Floor 4.
3. F lives immediately below D.
4. Two persons between F and C. (In Case 1, F=4 -> C must be Floor 1, but Floor 1 already holds B! Contradiction! Case 1 ELIMINATED!).
5. A lives immediately above G. (In Case 2: A=2, G=1).
6. E lives on one of the floors above B. (E=5).

Visual Solved Floor Grid:
Floor 7: [ D ]
Floor 6: [ F ]
Floor 5: [ E ]
Floor 4: [ B ]
Floor 3: [ C ]
Floor 2: [ A ]
Floor 1: [ G ]
