1. CORE METHOD & GOLDEN SPEED PROTOCOLS
--------------------------------------------------------------------
A) The "Laser-Focus / Target-First" Rule (લક્ષ્ય-કેન્દ્રીત ઝડપી રીત):
   - In RRB PO Prelims, 5 questions are asked on a 4-line Chinese Coding set.
   - FATAL MISTAKE (સમયનો બગાડ): Writing down all 16 words and all 16 codes on scratch paper before looking at the questions! This wastes 2.5 minutes!
   - WINNER'S STRATEGY (વિજેતાની રીત): Look at the TARGET WORD in the question first.
     1. If target word appears in EXACTLY 2 statements: Find the ONLY code common to those 2 statements!
     2. If target word appears in ONLY 1 statement: Eliminate the codes that appear elsewhere; the residual code is the answer!
     3. If 2 words appear together in 2 statements and nowhere else: They cannot be separated -> Answer is "EITHER ... OR" (અથવા).

B) The 2-Column Scratchpad Shorthand (જો જરૂર પડે તો રફ વર્ક):
   - Never write full words! Use 2-3 letter abbreviations:
     "bank exam easy crack" -> bnk exm esy crk = pe la zo ti
   - Use shapes for visual matching:
     Circle common words in St 1 & 2
     Box common words in St 1 & 3
     Underline common words in St 2 & 3

C) Order Independence Law (શબ્દ અને કોડનો ક્રમ સ્વતંત્ર છે):
   - "bank exam easy crack" = "pe la zo ti"
   - DOES NOT MEAN bank = pe, exam = la!
   - Positional mapping is 100% false; only logical elimination finds the true code.

D) Conditional / Table-Based Coding (શરતો આધારિત કોડિંગ):
   - A table of Digits/Symbols with corresponding Letter codes is given, followed by 3-4 specific conditions (e.g. "If first element is odd and last is even...").
   - Golden Rule: ALWAYS check conditions 1, 2, 3 FIRST against the given input before touching the table!

4. THE "MEANS" VS "IS CALLED" FORMULA (CRACKED & MASTERED)
--------------------------------------------------------------------
A) "IS CALLED" (Forward Lookup):
   • Rule: Real Truth -> Look forward for code.
   • Example: 'Red is called Yellow' -> Real is Red -> Answer is Yellow.

B) "MEANS" (Backward / Fill-in-the-Blank Lookup):
   • Formula: [ ? ] means [ Real Truth ]
   • Example 1: What does a thirsty person drink?
     Real Truth = water.
     Formula: [ ? ] means water.
     Statement: 'sky' means 'water' -> Answer is uniquely SKY!
   • Example 2: What colour is a ripe banana?
     Real Truth = yellow.
     Formula: [ ? ] means yellow.
     Statement: 'red' means 'yellow' -> Answer is uniquely RED!
