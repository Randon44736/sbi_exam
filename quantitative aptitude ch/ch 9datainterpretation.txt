1. CORE SHORTCUTS & FORMULAS FOR ALL DI SETS
--------------------------------------------
A) The 4 Universal DI Question Types:
   1. Ratio: Drop trailing zeros immediately before writing down (e.g. 1500:800 -> 15:8).
   2. "X is what % of Y": (X / Y) x 100.
   3. "X is what % MORE / LESS than Y":
      Formula: [Difference / (Value after "than")] x 100.
      * Exam Trap: The denominator is ALWAYS the reference value after "than"!
      * Real PDF Q9.4: Surat (2400) vs Gandhinagar (1200) -> (2400-1200)/1200 x 100 = 100% more.
   4. Average: Sum of values / Number of items.

B) Pie Chart Degree Trick (Real PDF Q9.13):
   - Full Circle = 360 degrees = 100%.
   - Benchmarks: 90 deg = 1/4 (25%), 180 deg = 1/2 (50%), 36 deg = 10%, 1 deg = 360/100 = 0.28%.
   - GOLDEN TIME SAVER: When finding ratio between slices in the SAME pie chart:
     NEVER calculate real values! Use degrees directly:
     * Engineering (54 deg) to Others (36 deg) = 54:36 = 3:2.
     * Arts (72 deg) to Others (36 deg) = 72:36 = 2:1.

C) Line / Bar Graph Gap Trick (Real PDF Q9.18):
   - When asked for difference between total of P and total of Q over 4 months:
     Sum the month-wise gaps instead of calculating two large sums!
     Gap = (45-35) + (50-40) + (60-55) + (70-65) = 10 + 10 + 5 + 5 = 30 thousand.

D) Caselet DI Strategy (Real PDF Page 39):
   - Read once, create a neat 2x3 or 2x2 grid on scratch paper first.
   - Once table is filled, all 5 questions can be answered in under 60 seconds.

[Q9.1: Find the ratio of Savings accounts in Surat to Current accounts in Ahmedabad.]
   ગુજરાતી: સુરતમાં બચત (Savings) ખાતાઓ અને અમદાવાદમાં ચાલુ (Current) ખાતાઓનો ગુણોત્તર શોધો.
   [A] 15:8  |  [B] 8:15  |  [C] 5:3  |  [D] 15:7  |  [E] 12:7
   Answer / જવાબ: [A] 15:8
   Step-by-Step (EN): From Table: Surat Savings = 1,500; Ahmedabad Current = 800. Ratio = 1,500 : 800 = 15:8.
   પદ્ધતિસર સમજૂતી (GU): કોષ્ટક પરથી: સુરત બચત = 1,500; અમદાવાદ ચાલુ = 800. ગુણોત્તર = 1,500 : 800 = 15:8.
   Easy Shortcut (EN): Drop 00 immediately → 15:8.
   સરળ શોર્ટકટ (GU): બંને પાછળના બે મીંડા ઉડાડી દો → 15:8.
   Common Exam Trap (સામાન્ય ભૂલ): ક્રમ બદલીને 8:15 ન ટીક કરી દેવો.

[Q9.2: Current accounts in Rajkot are approximately what percentage of Total accounts in Vadodara?]
   ગુજરાતી: રાજકોટમાં ચાલુ ખાતાઓ એ વડોદરાના કુલ ખાતાઓના કેટલા ટકા છે?
   [A] 44.5%  |  [B] 46.67%  |  [C] 48.33%  |  [D] 42.0%  |  [E] 52.5%
   Answer / જવાબ: [B] 46.67% (46 2/3%)
   Step-by-Step (EN): Rajkot Current = 700; Vadodara Total = 1,500. Required % = (700 / 1,500) × 100 = 700 / 15 = 140 /
   3 = 46.67%.
   પદ્ધતિસર સમજૂતી (GU): રાજકોટ ચાલુ = 700; વડોદરા કુલ = 1,500. ટકા = (700/1500) × 100 = 140/3 = 46.67%.
   Easy Shortcut (EN): 7/15 = 7 × 6.666% = 46.67%.
   સરળ શોર્ટકટ (GU): 1/15 = 6.67% યાદ રાખો, એટલે 7/15 = 46.67%.
   Common Exam Trap (સામાન્ય ભૂલ): રાજકોટ અને વડોદરાની કૉલમ અદલાબદલી ન થઈ જાય તેનું ધ્યાન રાખવું.

[Q9.3: Find the average number of Savings accounts across all 5 branches.]
   ગુજરાતી: તમામ 5 શાખાઓમાં બચત (Savings) ખાતાઓની સરેરાશ સંખ્યા શોધો.
   [A] 1,050  |  [B] 1,150  |  [C] 1,100  |  [D] 1,200  |  [E] 1,080
   Answer / જવાબ: [C] 1,100
   Step-by-Step (EN): Sum of Savings = 1,200 + 1,500 + 900 + 1,100 + 800 = 5,500. Average = 5,500 ÷ 5 = 1,100.
   પદ્ધતિસર સમજૂતી (GU): કુલ બચત ખાતા = 1200 + 1500 + 900 + 1100 + 800 = 5,500. સરેરાશ = 5,500 / 5 = 1,100.
   Easy Shortcut (EN): Assumed base 1,100 → deviations (+100 +400 −200 +0 −300) = 0 → Avg = 1,100!
   સરળ શોર્ટકટ (GU): (1200+800)=2000, (1500+900+1100)=3500 → કુલ 5500/5 = 1,100.
   Common Exam Trap (સામાન્ય ભૂલ): કુલ ખાતાઓ (Total) નો સરવાળો ભૂલથી ન કરી લેવો.

[Q9.4: Total accounts in Surat are what percent more than Total accounts in Gandhinagar?]
   ગુજરાતી: સુરતમાં કુલ ખાતાઓ ગાંધીનગરના કુલ ખાતાઓ કરતાં કેટલા ટકા વધુ છે?
   [A] 80%  |  [B] 120%  |  [C] 50%  |  [D] 100%  |  [E] 90%
   Answer / જવાબ: [D] 100%
   Step-by-Step (EN): Surat Total = 2,400; Gandhinagar Total = 1,200. More by = 2,400 − 1,200 = 1,200. % more = (1,200
   / 1,200) × 100 = 100%.
   પદ્ધતિસર સમજૂતી (GU): સુરત કુલ = 2,400; ગાંધીનગર કુલ = 1,200. તફાવત = 1,200. ટકા વધુ = (1200/1200) × 100 = 100%.
   Easy Shortcut (EN): Double value (1,200 → 2,400) ALWAYS equals +100% more.
   સરળ શોર્ટકટ (GU): જ્યારે કિંંમત બમણી (1200 થી 2400) હોય ત્યારે હંમેશા 100% વધુ હોય!
   Common Exam Trap (સામાન્ય ભૂલ): આધારમાં સુરત (2400) મૂકીને 50% જવાબ ટીક ન કરી દેવો; 'than Gandhinagar' હોવાથી
   છેદમાં 1200 આવે.

[Q9.5: If 25% of Savings accounts in Ahmedabad belong to females, find the number of male Savings accounts in]
   Ahmedabad.
   ગુજરાતી: જો અમદાવાદના બચત ખાતાઓમાંથી 25% મહિલાઓના હોય, તો અમદાવાદમાં પુરુષોના બચત ખાતા કેટલા હશે?
   [A] 900  |  [B] 850  |  [C] 960  |  [D] 800  |  [E] 1,000
   Answer / જવાબ: [A] 900
   Step-by-Step (EN): Ahmedabad Savings = 1,200. Male share = 100% − 25% = 75% (3/4). Male accounts = (3/4) ×
   1,200 = 900.
   પદ્ધતિસર સમજૂતી (GU): અમદાવાદ બચત ખાતા = 1,200. મહિલા 25% એટલે પુરુષ = 75% (3/4). પુરુષ ખાતા = 1200 × 3/4 =
   900.
   Easy Shortcut (EN): 75% of 1,200 = 3 × 300 = 900.
   સરળ શોર્ટકટ (GU): 1200 ના 25% (ચોથો ભાગ = 300) બાદ કરો: 1200 − 300 = 900.
   Common Exam Trap (સામાન્ય ભૂલ): મહિલાઓના ખાતા (300) ને બદલે અમદાવાદના કુલ ખાતા (2000) પર ગણતરી ન કરી લેવી.

[Q9.6: Find the percentage increase in Total loans (Home + Vehicle) from 2021 to 2023.]
   ગુજરાતી: 2021 થી 2023 સુધીમાં કુલ લોન (હોમ + વિહિકલ) માં કેટલા ટકાનો વધારો થયો?
   [A] 45%  |  [B] 50%  |  [C] 55%  |  [D] 40%  |  [E] 60%
   Answer / જવાબ: [B] 50%
   Step-by-Step (EN): 2021 Total = 240 + 160 = 400 Cr. 2023 Total = 360 + 240 = 600 Cr. Increase = 600 − 400 = 200 Cr.
   % Increase = (200 / 400) × 100 = 50%.
   પદ્ધતિસર સમજૂતી (GU): 2021 કુલ લોન = 240 + 160 = 400 કરોડ. 2023 કુલ = 360 + 240 = 600 કરોડ. વધારો = 200 કરોડ →
   (200/400) × 100 = 50%.
   Easy Shortcut (EN): 400 → 600 is cleanly +1/2 = 50%.
   સરળ શોર્ટકટ (GU): 400 પર 200 વધે એટલે અડધો ભાગ = સીધા 50%.
   Common Exam Trap (સામાન્ય ભૂલ): માત્ર હોમ લોન (240 થી 360 = +50%) જોકે અહીં બંને 50% છે, પરંતુ હંમેશા કુલ (Total)
   ગણો.

[Q9.7: Find the ratio of Vehicle loans in 2022 to Home loans in 2024.]
   ગુજરાતી: 2022 ની વિહિકલ લોન અને 2024 ની હોમ લોનનો ગુણોત્તર શોધો.
   [A] 4:7  |  [B] 3:8  |  [C] 3:7  |  [D] 5:7  |  [E] 2:5
   Answer / જવાબ: [C] 3:7
   Step-by-Step (EN): Vehicle 2022 = 180 Cr; Home 2024 = 420 Cr. Ratio = 180 : 420. Divide both by 60 → 3:7.
   પદ્ધતિસર સમજૂતી (GU): 2022 વિહિકલ લોન = 180; 2024 હોમ લોન = 420. ગુણોત્તર = 180 : 420 (60 વડે ભાગતાં) = 3:7.
   Easy Shortcut (EN): 18 : 42 ÷ 6 = 3 : 7.
   સરળ શોર્ટકટ (GU): 180 અને 420 માંથી 60 વડે ભાગતાં 3:7 મળે.
   Common Exam Trap (સામાન્ય ભૂલ): બાર ચાર્ટમાં ભૂરો (Home) અને કેસરી (Vehicle) રંગ ધ્યાનથી વાંચવો.

[Q9.8: Find the average Home loan per year from 2021 to 2024 (in ₹ Crore).]
   ગુજરાતી: 2021 થી 2024 સુધીની વાર્ષિક સરેરાશ હોમ લોન (કરોડ ₹ માં) શોધો.
   [A] 320 Cr  |  [B] 340 Cr  |  [C] 325 Cr  |  [D] 330 Cr  |  [E] 315 Cr
   Answer / જવાબ: [D] 330 Cr
   Step-by-Step (EN): Home loans across 4 years = 240 + 300 + 360 + 420 = 1,320 Cr. Average = 1,320 ÷ 4 = 330 Cr.
   પદ્ધતિસર સમજૂતી (GU): ચારેય વર્ષની હોમ લોન = 240 + 300 + 360 + 420 = 1,320 કરોડ. સરેરાશ = 1320 / 4 = 330 કરોડ.
   Easy Shortcut (EN): Equally spaced AP (240, 300, 360, 420)! Average = midpoint of middle two = (300 + 360)/2 = 330
   Cr.
   સરળ શોર્ટકટ (GU): ક્રમિક +60 ના અંતરે (240, 300, 360, 420) હોવાથી બરાબર વચ્ચેની કિંંમત (300+360)/2 = 330 કરોડ!
   Common Exam Trap (સામાન્ય ભૂલ): 4 ને બદલે 5 વડે ભાગાકાર ન થઈ જાય તેનું ધ્યાન રાખવું (અહીં 4 વર્ષ આપ્યા છે).

[Q9.9: In 2024, Vehicle loans formed what percentage of Total loans in that year?]
   ગુજરાતી: 2024 માં વિહિકલ લોન એ તે વર્ષની કુલ લોનના કેટલા ટકા હતી?
   [A] 38%  |  [B] 42%  |  [C] 36%  |  [D] 45%  |  [E] 40%
   Answer / જવાબ: [E] 40%
   Step-by-Step (EN): In 2024: Vehicle = 280 Cr, Home = 420 Cr ⇒ Total = 280 + 420 = 700 Cr. Percentage = (280 / 700)
   × 100 = 40%.
   પદ્ધતિસર સમજૂતી (GU): 2024 માં વિહિકલ = 280 અને હોમ = 420 → કુલ લોન = 700 કરોડ. ટકા = (280/700) × 100 = 40%.
   Easy Shortcut (EN): 280 / 700 = 4 / 10 = 40%.
   સરળ શોર્ટકટ (GU): 28/70 = 4/10 = 40% સીધું મનમાં.
   Common Exam Trap (સામાન્ય ભૂલ): છેદમાં કુલ 700 ને બદલે હોમ લોન 420 (280/420 = 66.67%) ન મૂકી દેવી.

[Q9.10: If Home loans in 2025 increase by 20% over 2024, what will be the Home loan amount in 2025?]
   ગુજરાતી: જો 2025 માં હોમ લોનમાં 2024 ની સરખામણીમાં 20% નો વધારો થાય, તો 2025 ની હોમ લોન કેટલી થશે?
   [A] 504 Cr  |  [B] 500 Cr  |  [C] 484 Cr  |  [D] 512 Cr  |  [E] 496 Cr
   Answer / જવાબ: [A] 504 Cr
   Step-by-Step (EN): 2024 Home loans = 420 Cr. +20% = +84 Cr. 2025 Home loans = 420 + 84 = 504 Cr.
   પદ્ધતિસર સમજૂતી (GU): 2024 ની હોમ લોન = 420 કરોડ. 20% વધારો = 420 ના 20% = 84 કરોડ. 2025 ની લોન = 420 + 84 =
   504 કરોડ.
   Easy Shortcut (EN): 420 × 1.2 = 42 × 12 = 504 Cr.
   સરળ શોર્ટકટ (GU): 420 નો 10% = 42, તો 20% = 84 → 420 + 84 = 504 કરોડ.
   Common Exam Trap (સામાન્ય ભૂલ): વિહિકલ લોન 280 પર 20% વધારીને ગણતરી ન થઈ જાય તે જોવું.

[Q9.11: Find the total number of applicants from Commerce.]
   ગુજરાતી: કોમર્સ (Commerce) ના કુલ ઉમેદવારોની સંખ્યા શોધો.
   [A] 20,400  |  [B] 21,600  |  [C] 22,000  |  [D] 21,000  |  [E] 19,800
   Answer / જવાબ: [B] 21,600
   Step-by-Step (EN): 360° = 72,000 applicants ⇒ 1° = 200. Commerce = 108° = 108 × 200 = 21,600 (note chart legend
   also shows 30% of 72,000 = 21,600).
   પદ્ધતિસર સમજૂતી (GU): 360° = 72,000 એટલે 1° = 200 ઉમેદવાર. કોમર્સ = 108° → 108 × 200 = 21,600.
   Easy Shortcut (EN): 108 × 200 = 21,600 (or 30% × 72,000).
   સરળ શોર્ટકટ (GU): 1° = 200 હોવાથી ડિગ્રીને સીધા 200 વડે ગુણો: 108 × 200 = 21,600.
   Common Exam Trap (સામાન્ય ભૂલ): ડિગ્રીને સીધા ટકા સમજીને 108 ન લઈ લેવા; કુલ 360° છે (100% નહીં).

[Q9.12: By how much are Arts applicants less than Science applicants?]
   ગુજરાતી: આર્ટ્સ (Arts) ના ઉમેદવારો સાયન્સ (Science) ના ઉમેદવારો કરતાં કેટલા ઓછા છે?
   [A] 3,200  |  [B] 4,000  |  [C] 3,600  |  [D] 3,400  |  [E] 2,800
   Answer / જવાબ: [C] 3,600
   Step-by-Step (EN): Difference in degrees = Science (90°) − Arts (72°) = 18°. Since 1° = 200, difference = 18 × 200 =
   3,600.
   પદ્ધતિસર સમજૂતી (GU): ડિગ્રીનો તફાવત = સાયન્સ (90°) − આર્ટ્સ (72°) = 18°. 1° = 200 હોવાથી તફાવત = 18 × 200 = 3,600.
   Easy Shortcut (EN): Subtract degrees FIRST (90° − 72° = 18°) → 18 × 200 = 3,600.
   સરળ શોર્ટકટ (GU): 18,000 અને 14,400 અલગ-અલગ શોધવાને બદલે સીધો ડિગ્રી તફાવત 18° × 200 = 3,600 કરો.
   Common Exam Trap (સામાન્ય ભૂલ): બંનેનો સરવાળો (90+72) ન કરી દેવો; 'less than' એટલે બાદબાકી.

[Q9.13: Find the ratio of Engineering applicants to Others applicants.]
   ગુજરાતી: એન્જિનિયરિંંગ (Engineering) અને અન્ય (Others) ઉમેદવારોનો ગુણોત્તર શોધો.
   [A] 2:3  |  [B] 4:3  |  [C] 5:3  |  [D] 3:2  |  [E] 5:2
   Answer / જવાબ: [D] 3:2
   Step-by-Step (EN): Engineering = 54°, Others = 36°. Because both come from the same pie total, ratio of counts =
   ratio of degrees = 54 : 36 = 3:2.

   ગુજરાતી: ખૂટતી કિંંમત [ A ] (Q1 માં વેચાયેલા ટેબ્લેટ) શોધો.
   [A] 1,500  |  [B] 1,600  |  [C] 1,800  |  [D] 1,400  |  [E] 2,400
   Answer / જવાબ: [B] 1,600
   Step-by-Step (EN): In Q1, Total Devices = 4,000 and Phones : Tablets = 3 : 2 (total = 5 units). 1 unit = 4,000 ÷ 5 = 800.
   Tablets [A] = 2 units = 2 × 800 = 1,600.
   પદ્ધતિસર સમજૂતી (GU): Q1 માં કુલ ડિવાઇસ = 4,000 અને ગુણોત્તર 3:2 (કુલ 5 ભાગ). 1 ભાગ = 4000/5 = 800. ટેબ્લેટ [A] = 2 ×
   800 = 1,600.
   Easy Shortcut (EN): 4,000 × (2/5) = 1,600.
   સરળ શોર્ટકટ (GU): 4,000 ના 2/5 (40%) = 1,600.
   Common Exam Trap (સામાન્ય ભૂલ): ફોનની સંખ્યા (2,400) ભૂલથી ટેબ્લેટ [A] માં ટીક ન કરી દેવી.

[Q9.27: Find the missing value [ B ] (Total Devices sold in Q2).]
   ગુજરાતી: ખૂટતી કિંંમત [ B ] (Q2 માં કુલ ડિવાઇસ) શોધો.
   [A] 4,500  |  [B] 4,200  |  [C] 4,800  |  [D] 5,000  |  [E] 3,600
   Answer / જવાબ: [C] 4,800
   Step-by-Step (EN): In Q2, Phones : Tablets = 5 : 3 (total = 8 units) and Tablets = 1,800 (3 units). So 1 unit = 1,800 ÷ 3
   = 600. Total Devices [B] = 8 units = 8 × 600 = 4,800.
   પદ્ધતિસર સમજૂતી (GU): Q2 માં ગુણોત્તર 5:3 અને ટેબ્લેટ (3 યુનિટ) = 1,800 → 1 યુનિટ = 600. કુલ ડિવાઇસ [B] = (5+3) = 8
   યુનિટ = 8 × 600 = 4,800.
   Easy Shortcut (EN): 3 units = 1,800 (×600) → 8 units = 4,800.
   સરળ શોર્ટકટ (GU): 3 યુનિટ = 1,800 → 1 યુનિટ = 600 → કુલ 8 યુનિટ = 4,800.
   Common Exam Trap (સામાન્ય ભૂલ): ફોનની સંખ્યા 5 × 600 = 3,000 શોધીને [B] માં ટીક ન કરી દેવી; [B] 'Total Devices' માં છે.

[Q9.28: Find the missing ratio [ C ] (Phones : Tablets in Q3).]
   ગુજરાતી: ખૂટતો ગુણોત્તર [ C ] (Q3 માં ફોન : ટેબ્લેટ) શોધો.

   3,600 : 2,400 = 3:2.
   પદ્ધતિસર સમજૂતી (GU): Q3 માં કુલ 6,000 માંથી ટેબ્લેટ 2,400 છે, એટલે ફોન = 6,000 − 2,400 = 3,600. ગુણોત્તર [C] = 3,600 :
   2,400 = 3:2.
   Easy Shortcut (EN): 36 : 24 ÷ 12 = 3 : 2.

   Common Exam Trap (સામાન્ય ભૂલ): 6000 : 2400 = 5:2 કરી દેવાની ભૂલ ન કરવી; પહેલા કુલમાંથી ટેબ્લેટ બાદ કરી ફોન શોધો.

[Q9.29: Find the missing value [ D ] (Tablets sold in Q4).]
   ગુજરાતી: ખૂટતી કિંંમત [ D ] (Q4 માં વેચાયેલા ટેબ્લેટ) શોધો.

[Q9.30: Find the total number of Phones sold across all four quarters (Q1 to Q4).]
   ગુજરાતી: ચારેય ત્રિમાસિક ગાળા (Q1 થી Q4) માં વેચાયેલા કુલ ફોનની સંખ્યા શોધો.
